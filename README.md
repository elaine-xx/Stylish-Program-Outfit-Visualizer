# Interactive Outfit Visualizer 👗👕

An interactive fashion design tool built in **Processing** allowing users to mix and match outfits, switch model types, and generate looks based on pre-set themes or mood keywords.  

This project showcases **modular programming**, **user input handling**, and **visual rendering** and combines creativity with software design!

---

## 🌟 Features

- **Dynamic Outfit Customization:** Switch tops, bottoms, and accessories for two model types (masculine and feminine).  
- **Preset Looks:** Six curated outfit presets, each accessible through clickable buttons (1–6).  
- **Mood-Based Styling:** Enter keywords representing moods or aesthetics (e.g., “professional,” “cozy”) to generate matching outfit combinations.  
- **Interactive UI:** Smooth transitions and visual fit to models for a polished user experience.  
- **Modularized Code:** Built with reusable Processing classes and functions for efficient updates and scalability.

---

## 🧠 Inspiration

This project was inspired by the pain point of deciding what to wear plus the fun in exploring fashion styles.
